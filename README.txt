PUBLICACIÓN EN GITHUB PAGES
1. Crea un repositorio público llamado TU-USUARIO.github.io.
2. Sube TODO el contenido de esta carpeta manteniendo la estructura.
3. Activa Settings > Pages > Deploy from branch > main / root.
4. Sustituye YOUR-USERNAME en robots.txt y sitemap.xml por tu usuario real de GitHub.
5. Cuando tengas la URL final, conviene actualizar las URLs canónicas/JSON-LD con el dominio definitivo.
6. Añade la propiedad del sitio a Google Search Console y envía sitemap.xml.

NOTAS
- Las fotografías de esta versión son las imágenes reales suministradas en la conversación; no se ha generado ningún rostro artificial.
